# 5€ FANTASMA

Prenoti. Accumuli. Risparmi.

Prototipo navigabile (modalità DEMO) di una piattaforma italiana per prenotazioni al ristorante, caparre digitali (18% configurabile) e Club Fantasma (coupon ogni 8 prenotazioni completate).

## Avvio in locale
Apri `index.html` nel browser. Nessuna installazione richiesta. I dati sono salvati nel `localStorage`.

## Stato
- Pagamenti simulati, nessun addebito reale.
- Da fare: Next.js + TypeScript + Tailwind, Supabase, Stripe con webhook verificati, ruoli e policy server-side, QR code, calendario e tavoli.
